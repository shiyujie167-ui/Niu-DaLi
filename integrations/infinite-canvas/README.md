# 无限画布网关默认配置

配套画布仓库：`https://github.com/basketikun/infinite-canvas.git`，固定提交 `dab19adc0847e32e39b7fc8ff90cb392561fb826`（v0.19.0）。画布独立运行；本目录保存默认配置补丁，不包含完整画布源码。

## 首次访问自动配置

运行环境需有 Bun 和 Node.js 20.19+ 或 22.12+。在画布构建前应用补丁：

```bash
git clone https://github.com/basketikun/infinite-canvas.git /path/to/infinite-canvas
git -C /path/to/infinite-canvas checkout dab19adc0847e32e39b7fc8ff90cb392561fb826
sh integrations/infinite-canvas/apply-defaults.sh /path/to/infinite-canvas
cd /path/to/infinite-canvas/web
bun install --frozen-lockfile
bun run test
bun run typecheck
bun run dev --port 3001 --strictPort
```

脚本校验固定版本、检查补丁是否可应用，并支持重复执行。发布时在同一 `web/` 目录运行 `bun run build`，部署生成的 `dist/`。仅部署主项目不会自动更新独立画布网站。

首次访问默认渠道的 Base URL 为 `https://8.216.57.93`，模型目录请求为 `https://8.216.57.93/v1/models`。Base URL 不应填写完整的 `/v1/models`，否则生成接口会拼接到错误路径。API Key 留空，由每位用户填写自己的 Key。

默认注册目录中已确认的四个视频模型：`Sd-2.0fast`、`Sd-2.0满血933`、`Sd-2.5`、`minmax-h3`，默认选择 `Sd-2.0fast`、4 秒、720p、16:9、参考模式。这些模型显式标记为视频，避免按名称误判为文本。当前目录未返回图像、文本或音频模型，因此不预选这些能力的模型；不同 Key 的实际模型权限可能不同，可在渠道编辑器中重新获取目录。

视频使用画布内置 OpenAI 协议：Bearer 鉴权，创建请求 `/v1/videos`，轮询 `/v1/videos/:id`。旧示例中的供应商原生脚本已移除；它们请求 `/api/v1/models`、`/api/v1/video-tasks`，直接连接此网关会返回 404。

补丁同时适配该 HTTPS 网关的四个默认视频模型：提交 `aspect_ratio`、`resolution`、`with_audio`，图片通过重复的 `reference_images` 文件字段上传。这样可以兼容当前部署的旧插件，避免 `resolution_name`、`generate_audio`、`watermark`、`mode` 和首尾帧文件字段被拒绝；其他地址、其他模型和自定义脚本仍保持原调用方式。新旧网关插件的离线请求解析与上游请求构造均已验证，无需为了这项字段修复部署服务器。

实际测试已使用 `Sd-2.5`、720p、16:9、4 秒完成文字生成、播放和下载，可先用这一组合验证。`Sd-2.0fast` 本次任务因上游繁忙失败，且不支持 480p；`minmax-h3` 需要参考图和 768p 或 2k，不能套用 720p。此补丁不自动提高用户选择的分辨率或改变时长，模型能力限制仍由服务端校验。该网关将所有图片作为普通参考图，不支持单独指定首尾帧或水印；视频和音频文件上传尚未适配。

任务失败或取消时优先结束轮询，不能把残留视频地址当作成功。该网关的标准查询响应缺少失败详情时，补查同一任务的 `/mengwuxian/api/v1/video-tasks/:id`，沿用用户鉴权且不重新提交生成。补查失败时保留原失败提示。

已有浏览器的渠道、Key 和偏好保留。补丁不会清空或强制导入本地存储，也不会影响 WebDAV 和提示词来源。主项目的站点设置中可填写「无限画布入口地址」，本地示例为 `http://localhost:3001`。

已有渠道名称中的供应商后缀会在加载、编辑和导入时清理；模型菜单、配置页与历史记录的模型兜底标题使用清理后的展示名称。渠道 ID、API 地址、Key、自定义脚本和用户填写的历史标题保持不变。

视频工作台和画布节点共用模型能力限制。不支持的清晰度及比例显示为灰色并禁用，宽高根据有效清晰度/比例展示；已知模型禁用自定义清晰度和宽高。切换模型后不自动改变清晰度，旧参数不兼容时提示用户选择；请求前再次校验，防止历史记录或 Agent 参数绕过界面限制。能力仅用于当前网关的四个内置模型，自定义脚本和其他渠道保持原行为。

| 模型 | 可选清晰度 | 可选比例 |
| --- | --- | --- |
| Sd-2.0fast | 720p、1080p | 1:1、3:4、4:3、16:9、9:16、21:9 |
| Sd-2.0满血933 | 720p、1080p、4K | 1:1、3:4、4:3、16:9、9:16、21:9 |
| Sd-2.5 | 480p、720p、1080p | 1:1、3:4、4:3、16:9、9:16、21:9 |
| minmax-h3 | 768p、2K | 1:1、16:9、9:16 |

能力来自网关任务插件的模型契约，供应商能力变更时需同步更新补丁。2K/4K 作为原始档位提交，不推断具体像素，宽高显示为空；服务端仍执行最终校验。

## 手动导入与代理

`config.example.json` 是无密钥的手动导入备选。导入会替换该浏览器的渠道、偏好、WebDAV 和提示词来源设置；请先导出备份，再在「配置 → 导入配置」中选择文件。

默认关闭本地代理。此网关已验证允许跨域请求，访客无需运行本机代理。如果换用不允许跨域的网关，可在本机启动 `node canvas-proxy/index.js`，再手动启用 `http://127.0.0.1:23210`；公网部署不要让访客默认依赖环回地址。

## 88API Seedance 多素材内置接入

新增 `seedance.patch`，由 `apply-defaults.sh` 在默认补丁后应用，支持已应用旧补丁的目录升级及重复执行。

网关需运行 `88api-seedance` 1.1.0 与本次 `/v1/media/uploads` 上传凭证接口。专用渠道类型为 New API，绑定该插件，Base URL 为 `https://api.88api.ai`；上游 Key 只保存在该渠道。用户画布配置本地 `http://localhost:3002` 或已升级的 HTTPS 网关及用户网关 Key，渠道的“视频接入方式”选择“88API Seedance／SD（通过我们的网关）”，模型能力选择“视频”，清空旧手册的单图自定义脚本并保存外层渠道。不要覆盖整份浏览器配置；自定义脚本仍优先于内置请求。

- 支持 `seedance-2.5官方版`、`seedance-2.0官方版`、`seedance-2.0-fast官方版`、`seedance-2.0-mini官方版`、`SD2.0`、`SD2.5`；同时识别文档中的 `SD2.0 480P` 等固定档位旧名称。只配置当前上游 Key 实际有权限的模型，不因插件声明而推断账号已开通。
- 只连素材不写文字时补充“保持参考素材中的主体外观和风格，生成自然连贯的动作与镜头”；无素材无文字仍拒绝。
- 参考模式按模型接受多图、视频、音频；首尾帧模式按连接顺序使用第一、第二张图片，不与普通素材混用。mini 无首尾帧。素材先取得临时上传凭证、完成 PUT，再提交一次生成 POST。
- 官方 2.5／2.0／fast：720p；mini：480p／720p；SD2.5：480p／720p／1080p；SD2.0 另支持 4K。固定档位旧模型只能使用名称中档位，不静默换模型或分辨率。
- 2.5 图片／视频／音频各为 30／10／10，2.0 系列为 9／3／3；SD2.0 总计最多 12。时长 2.5 为 4–30 秒，其余 4–15 秒。上传接口单文件上限沿用上游 100,000,000 字节，图片沿用已有 10 MiB 工程上限；上游仍可能因素材实际尺寸、编码或时长拒绝。
- 上传凭证经现有令牌、模型权限、分组和插件渠道选择；只向 88API 官方申请，只接受官方素材域名和专用上传头，拒绝重定向，禁止把网关／上游 Bearer 发给素材域名。
- 创建返回公共任务 ID 后沿用画布现有任务保存和查询；超时先查询原任务。尚未收到 ID 的创建失败不能推断上游未接收，避免人工重复提交。

本次只改变接入能力，不设置或覆盖管理员价格、分组、用户额度和上游凭据。真实上传、各模型视频生成播放、费用结算仍需要已配置渠道的账号验收；离线用例不代表上游实测。


### 直连 88API 的现有渠道

官方地址 `https://api.88api.ai` 或 `https://api.88api.ai/v1` 自动使用多素材接入，不要求改成本地网关、不改现有 Key。已知模型先逐张上传图片再发送有序 `images` URL 数组与用户提示词；全能参考模式不会生成 `firstFrame`／`lastFrame`。上传凭证请求只含上游规定的摘要、大小和 MIME；网关模式保留选路所需的模型字段。其它供应商同名模型不自动切换。自定义脚本仍保持优先。

部署后刷新原画布标签页，核对渠道编辑页出现“88API 直连（自动多素材上传）”。原失败节点的旧错误记录会保留，不能将它当作新版本重新提交后的结果。接口参数回归和构建已通过；真实上传及付费生成需另行验收。
