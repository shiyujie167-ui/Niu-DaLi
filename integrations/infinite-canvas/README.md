# 本地无限画布接入快照

配套画布仓库：`https://github.com/basketikun/infinite-canvas.git`，本次使用提交 `dab19adc0847e32e39b7fc8ff90cb392561fb826`（v0.19.0）。画布独立运行；本目录保留本次渠道与模型配置，不包含画布源码副本。

在实际使用的浏览器中打开画布，进入「配置 → 导入配置」并选择 `config.example.json`。导入会替换该浏览器的渠道、偏好、WebDAV 和提示词来源设置；请先导出原有配置备份。导入后编辑「大力牛视频 · zhi168」，填写自己的 API Key。示例文件不包含密钥。

示例注册六个视频模型，默认 `Sd-2.0fast`、4 秒、720p、16:9、参考模式。模型目录使用 `https://www.zhi168.it.com/api/openai`；每个视频模型附带原生任务调用脚本，避免使用上游不兼容的默认视频表单。

浏览器配置保存在该浏览器的本地存储中，不会随容器重启或跨浏览器自动同步。主项目的站点设置中可填写「无限画布入口地址」，本地示例为 `http://localhost:3001`。

## 本地代理

示例已启用 `http://127.0.0.1:23210`。在上述固定版本的画布仓库内执行 `node canvas-proxy/index.js` 启动项目自带代理。只在本机使用；密钥由浏览器携带，不写入本目录。

## 已知限制

此提交保存当前接入状态，不代表完整图生视频流程已经修复：

- 公网图片 URL 通过原生 `reference_image_urls` 调用已单独实测出片。
- 当前画布会把本地参考图转换为 Data URL，脚本仍通过 multipart 上传；上游返回素材地址 403。尚未接入将本地图片转换为可访问公网 URL 的存储，不能宣称上传自己的图片已可出片。
- 脚本当前将图片作为参考素材，不实现严格首尾帧控制。
- 本次文生视频脚本验证创建了任务，但上游随后返回 `MATERIAL_LIMIT_EXCEEDED`，扣费为 0。
- 模型参数由上游目录校验；切换模型后可能需要调整分辨率与时长。脚本轮询沿用画布默认值，刷新期间恢复脚本任务仍受原画布限制。

无需、也不应将真实 API Key、浏览器存储导出、数据库备份或用户图片提交到 Git。
